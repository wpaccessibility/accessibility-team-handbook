# WordPress plugin accessibility

Creating a plugin that supports accessibility is mostly about setting healthy defaults. This includes:

- ensuring the menus are accessible from the keyboard,
- checking that default color contrast meets standards,
- that the HTML structure uses semantically correct code.

Extended information about web accessibility and how to test and to apply this for your work is documented in the [WP Accessibility Knowledge Base](https://wpaccessibility.org/docs/accessibility-ready/).

There are no accessibility requirements for plugins in the WordPress plugin directory. This is because of the labor required to test plugins for accessibility. However, you are strongly encouraged to consider accessibility when creating or updating your plugins.
