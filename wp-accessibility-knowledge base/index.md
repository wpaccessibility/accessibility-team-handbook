## WP Accessibility Knowledge Base

Documentation about accessibility for WordPress users and creators. For the community, by the community.

This dedicated website for WordPress accessibility contains information about:

- How to [start with accessibility](https://wpaccessibility.org/docs/start/).
- Accessibility [standards and best practice](https://wpaccessibility.org/docs/topics/).
  - [WCAG and compliance](https://wpaccessibility.org/docs/topics/wcag/)
  - [WCAG vs best practice](https://wpaccessibility.org/docs/topics/best-practice/)
  - [Content and images](https://wpaccessibility.org/docs/topics/content/)
  - [Design & user experience](https://wpaccessibility.org/docs/topics/design/)
  - [Frontend code](https://wpaccessibility.org/docs/topics/code/)
  - [Web forms](https://wpaccessibility.org/docs/topics/forms/)
- [Testing](https://wpaccessibility.org/docs/testing/) for accessibility.
- [Legislation](https://wpaccessibility.org/docs/legislation/).

And many resources and examples.
